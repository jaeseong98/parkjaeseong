Claude Code 중심의 개발

반복적인 구현은 에이전트에 맡기고, 저는 문제 정의와 구조 설계, 결과 검증에 시간을 씁니다. 이 방식을 파트에 정착시켜 파트 전체의 개발 속도를 끌어올렸습니다.

현업이 계속 쓰는 구조

AI 전환의 성패는 모델 성능이 아니라 신뢰 구조에 달려 있습니다. 비개발 직군이 AI의 결과를 직접 검토·수정하고, 그 수정이 다시 시스템에 반영되게 했을 때 비로소 AI가 업무의 일부가 됐습니다.
