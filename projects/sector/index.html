Project 03

업종분류 전수조사 자동화

반기마다 코스피·코스닥 전 종목 업종분류 검수 · 아키텍처는 인덱스개발팀과 설계, 개발 전담

회사는 반기마다 상장사 전 종목의 업종분류를 다시 검토합니다. 담당자가 공시를 열어 매출 비중을 손으로 계산하고 분류를 바꿀지 판단하는 일이 종목마다 반복됐습니다. AI가 공시를 읽어 업종 후보를 근거와 함께 제시하고, 매출 집계와 최종 판정은 파이썬 코드가 맡는 구조로 다시 만들었습니다. 사업 개요와 매출 현황을 각각 근거로 삼는 두 모델의 판단이 일치하면 신뢰, 갈리면 검토 신호로 삼는 교차검증을 넣었고, 담당자가 근거를 보고 확정하는 검수 웹 도구까지 만들었습니다.
