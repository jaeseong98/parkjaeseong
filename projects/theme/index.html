Project 02

테마 대시보드 구축

2025.09 ~ 2026.06 · 증권 리포트 기반 투자정보 서비스 '리타민'의 테마 선제 발굴

고객에게 유의미한 테마 정보를 제공하려면 시장에서 부상하는 테마를 먼저 찾아야 하는데, 담당자의 감과 수작업 탐색에 의존하고 있었습니다. 뉴스·공시·리포트에서 LLM으로 테마 키워드를 추출하고 지표화하는 대시보드를 프론트엔드부터 서버, DB까지 단독으로 구축했습니다.
