Problem

Manual Index Development
수작업과 경험에 묶여 있던 지수 개발

테마 지수를 만들려면 뉴스와 공시를 뒤져 테마를 잡고, 종목을 고르고, 검증하는 과정을 반복해야 합니다. 이 전 과정이 담당자 개인의 수작업과 경험에 묶여 있어 속도와 일관성 모두 한계가 있었고, 분석 결과는 개인 문서로만 남아 조직의 자산이 되지 못했습니다.

수작업 의존

테마 발굴부터 종목 선정, 검증까지 소수 담당자의 수작업과 경험에 의존. 담당자가 바뀌면 기준도 바뀌는 구조.

축적되지 않는 결과

분석 결과가 개인 PC의 문서로만 존재. 같은 조사를 반복해도 조직에는 아무것도 남지 않음.

문제의 재정의

사람이 판단할 일과 기계가 처리할 일을 분리하면, 흩어져 있던 단계들을 하나의 파이프라인으로 묶고 결과를 축적할 수 있다고 판단했습니다.

Solution

AI Index Development Pipeline
지수 개발 5단계 파이프라인 설계
